Calculator Web Application 

1. Project Description
The Calculator Web Application is a simple, responsive calculator built using HTML, CSS, and JavaScript. It allows users to perform basic arithmetic calculations through an interactive interface.
The project demonstrates fundamental web development concepts, including DOM manipulation, event handling, conditional statements, functions, and CSS Grid.

2. Features
Addition (+)
Subtraction (-)
Multiplication (×)
Division (÷)
Decimal number support
Clear button to reset the calculator
Backspace button to delete the last digit
Support for chained calculations
Error handling for division by zero
Responsive user interface
CSS Grid layout
Event listeners for button interactions

3. Technologies Used
HTML5: Structures the calculator interface.
CSS3: Styles the calculator and arranges buttons using CSS Grid.
JavaScript: Implements calculation logic and user interactions.

4. Project Structure
calculator/
├── index.html
├── style.css

└── README.md
index.html — Contains the calculator's structure and buttons.
style.css — Defines the calculator's appearance and layout.
script.js — Handles calculations, button clicks, and error handling.
README.md — Provides project documentation.

5. How to Run the Project
Open Visual Studio Code.
Open the calculator project folder.
Make sure all project files are in the correct locations.
Install the Live Server extension if it is not already installed.
Right-click index.html.
Select Open with Live Server.
The calculator will open in your default web browser.

6. How to Use
Click the number buttons to enter a number.
Select an arithmetic operator.
Enter the next number.
Press = to display the result.
Press C or the Clear button to reset the calculator.
Use the backspace button to delete the last digit.
Example
5 + 3 × 2 = 11
The calculator evaluates multiplication before addition.
Error Handling
Division by zero is handled by displaying an error instead of returning a valid numerical result.
