Dr. Aklilu Lemma Tribute Page

1. Project Description
The Dr. Aklilu Lemma Tribute Page is a responsive informational webpage dedicated to Dr. Aklilu Lemma, an Ethiopian scientist internationally recognized for his research on endod, a plant investigated for its potential in controlling the freshwater snails that transmit schistosomiasis.
The purpose of this project is to honor his scientific contributions and introduce visitors to his life, achievements, and legacy.
The webpage is developed using HTML and CSS.

2. Features
Introduction to Dr. Aklilu Lemma
Portrait image
Biographical information
Explanation of his scientific contributions
Timeline of important achievements
Inspirational quotation
Information about his legacy
Reference links for further reading
Multiple background colors
Different font styles
Responsive layout for different screen sizes

3. Technologies Used
HTML5: Structures the webpage and organizes its content into sections.
CSS3: Controls the page layout, typography, colors, and responsive design.

index.html — Contains the tribute page content.
style.css — Defines the visual design and responsive layout.
README.md — Provides project documentation.

5. How to Run the Project
Open Visual Studio Code.
Open the aklilu-lemma-tribute folder.
Ensure that index.html and style.css are in the same folder.
Right-click index.html.
Select Open with Live Server.
The tribute page will open in your browser.
An internet connection is required to load the externally hosted portrait image and access the linked reference websites.
